Impor Database Siswa

Pilih file Excel (.xlsx) atau CSV, atau tempel data langsung dari Excel (baris pertama = judul kolom). Kolom dikenali otomatis, mis. Nomor Induk, NISN, Nama, L/P, Kelas, Tempat Lahir, Tanggal Lahir, Agama, Alamat, Nama Ayah, Nama Ibu.

Database Online (Google Sheets)

Hubungkan aplikasi ke Google Sheets milik sekolah agar data tersimpan online dan sama di semua perangkat. Pengaturan ini cukup dilakukan sekali per perangkat.

  1. Buat Google Sheet baru, lalu menu Ekstensi > Apps Script.
  2. Klik tombol di bawah untuk menyalin kode, hapus isi editor, tempel, lalu ganti KUNCI dengan kata sandi Anda dan simpan.
  3. Terapkan > Deployment baru > Aplikasi web. Jalankan sebagai: Saya. Akses: Siapa saja. Izinkan akses.
  4. Salin URL berakhiran /exec ke kolom di bawah, isi kunci yang sama, lalu Hubungkan.

Cadangan & Pemulihan

Salin teks JSON ini sebagai cadangan seluruh buku induk. Untuk memulihkan, tempel kembali lalu tekan “Pulihkan”.
